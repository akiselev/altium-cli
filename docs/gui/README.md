# GUI Planning Index

This directory captures the architecture and UX planning work for turning
`autopcb-viewer` into an IDE-style shell (`autopcb-studio`).

## Documents

- `architecture.md`: proposed shell architecture for egui/eframe + PCB workflows.
- `features.md`: concrete feature inventory and phased rollout.
- `research.md`: external references and decisions derived from online research.

## Scope

This is design-only planning. No implementation decisions in these docs should be
considered final until reviewed against code constraints and performance testing.
